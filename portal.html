Course Videos

🎥 How to add a video:

1. In the Cloudflare dashboard, open R2 → course-videos and upload the MP4. Use a file name without spaces, for example Module-01-Intro.mp4.
2. In the Video URL field below, type r2: and the file name, for example r2:Module-01-Intro.mp4.
3. Add title, module, duration, and notes, then click Add Lesson.

Videos are private: only logged-in students with active access (and admins) can play them, through links that expire after a few hours. Never upload course videos to GitHub, which is public.
